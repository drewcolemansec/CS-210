# CS-210 Project Three — Corner Grocer

## Project Summary

For this project, I built a C++ program that tracks how often different grocery items are purchased. The idea was to help Corner Grocer figure out which products sell the most so they could make better decisions about their store layout. The program reads a text file and allows users to search for items, see how many times each item was purchased, and view the results as a histogram.

## Reflection

**What did you do particularly well?**

I think I did a good job making the program simple to use while still including everything it needed. I wanted someone to be able to open it and understand what to do without needing instructions. I also kept the code organized instead of trying to put everything in one place.

**Where could you improve your code?**

I would probably improve the error handling and make the search function more efficient. Right now, it works well for a small grocery store, but if it was processing thousands of different products, I'd want it to handle that information more efficiently.

**What was most challenging, and how did you overcome it?**

The biggest challenge for me was getting the file handling and item tracking to work together. I understood what I wanted the program to do, but figuring out how to actually organize the data took some work. Breaking it down into smaller pieces and testing as I went made it a lot easier. I also used Visual Studio, zyBooks, and AI assistance when I needed help understanding certain parts.

**What skills will transfer to future projects?**

I think the biggest thing I'll take from this project is learning how to organize a program properly. Working with classes, maps, and files will definitely come up again, especially as I get into more advanced programming. I also got more comfortable troubleshooting problems instead of immediately starting over when something didn't work.

**How did you make the program maintainable, readable, and adaptable?**

I separated the code into different files and used functions for each major feature. I also included comments and descriptive names so it would be easier to come back to later. If I wanted to add more features in the future, I wouldn't have to completely rebuild the program to do it.
